## 이슈 1: afternoon.js 로컬 실행 시 GitHub 커밋 401 오류

### 증상
`node --env-file=.env scripts/afternoon.js` 실행 시 모범 답안 슬랙 발송은 성공하나 GitHub 커밋에서 401 오류 발생.

```
Error: GitHub commit 실패: 401 {"message":"Bad credentials"...}
```

### 원인
`lib/github.js`의 `commitDailyLog`가 `GITHUB_TOKEN`을 우선 사용하는데, 로컬 `.env`에 있는 `GITHUB_TOKEN`이 만료된 40자 구 토큰이었음. 유효하지 않은 값이지만 non-empty string이라 `|| STUDY_GITHUB_TOKEN` fallback이 동작하지 않음.

### 해결
`lib/github.js`에서 토큰 우선순위를 `STUDY_GITHUB_TOKEN || GITHUB_TOKEN`으로 변경.
- 로컬: `STUDY_GITHUB_TOKEN`(유효한 Classic PAT) 사용
- GitHub Actions: `STUDY_GITHUB_TOKEN` secrets도 설정되어 있어 동작 무관

### 관련 파일
- `lib/github.js` — 토큰 우선순위 수정

### 커밋
`1dedc1a` — fix: commitDailyLog 토큰 우선순위 수정 (STUDY_GITHUB_TOKEN 우선)

## 이슈 2: node --env-file 실행 시 MODULE_NOT_FOUND 오류

### 증상
```
Error: Cannot find module '/var/folders/.../cmux-claude-node-options/restore-node-options.cjs'
```

### 원인
Claude Code 내부에서 `NODE_OPTIONS` 환경변수를 임시 파일 경로로 설정하는데, 해당 파일이 세션 재시작 등으로 삭제된 상태에서 `node` 실행 시 preload 실패.

### 해결
`node` 실행 전 `unset NODE_OPTIONS` 추가.

```bash
unset NODE_OPTIONS && node --env-file=.env scripts/study.js
```
