# 2026-05-15 트러블슈팅

## 이슈 1: 자정 이후 Slack 답변이 GitHub에 저장 안 됨

### 증상
- 아침 질문에 자정을 넘겨서 답변했을 때, 슬랙 피드백은 정상적으로 왔지만 Redis와 GitHub에 답변이 저장되지 않음
- `afternoon.js` 실행 시 "오늘의 질문을 찾을 수 없습니다" 오류 발생

### 원인
`api/slack.js`의 `handleAnswer`에서 `getQuestion()`이 `todayKey('question')`으로 오늘 날짜 기준 Redis 키를 조회함.
자정(00:00 KST)이 지나면 `todayKey`가 다음 날 날짜를 반환하지만, 질문은 전날 날짜 키로 저장되어 있어 조회 실패 → 조기 리턴.

```
예: 2026-05-14 08:00에 발송된 질문 → Redis 키: daily-study:2026-05-14:question
    2026-05-15 00:19에 답변          → todayKey 반환값: 2026-05-15 → 질문 못 찾음
```

### 해결
`lib/redis.js`에 `getQuestionForDate(date)`, `getYesterdayDateKST()` 추가.
`api/slack.js`의 `handleAnswer`에서 오늘 질문이 없으면 어제 질문을 fallback으로 조회.

```js
// api/slack.js
let questions = await getQuestion();
if (!questions || !Array.isArray(questions) || questions.length === 0) {
  questions = await getQuestionForDate(getYesterdayDateKST());
}
```

### 관련 파일
- `api/slack.js` — `handleAnswer` 수정
- `lib/redis.js` — `getQuestionForDate`, `getYesterdayDateKST` 추가
