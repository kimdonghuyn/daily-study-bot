# 상속과 다형성: 게임 캐릭터 관리 시스템

## 모범 답안

### 1. 문제점 분석

상속과 다형성이 없다면:
```java
// ❌ 안티패턴: 타입 체크와 조건문의 무한 반복
public void attack(String characterType) {
    if (characterType.equals("warrior")) {
        // 전사 공격 로직
        System.out.println("검으로 베기!");
    } else if (characterType.equals("mage")) {
        // 마법사 공격 로직
        System.out.println("마법 시전!");
    } else if (characterType.equals("archer")) {
        // 궁수 공격 로직
        System.out.println("화살 쏘기!");
    }
    // 성기사 추가 시 또 다시 수정... 악순환
}
```

**문제점:**
- 새 캐릭터 추가 시마다 기존 코드 수정 (Open-Closed Principle 위반)
- 타입 체크 로직 중복
- 유지보수 어려움, 버그 발생 확률 증가

### 2. 상속과 다형성으로 해결

```java
// ✅ 상속을 통한 공통 속성/행동 정의
public abstract class Character {
    protected String name;
    protected int health;
    protected int level;
    
    public Character(String name, int health, int level) {
        this.name = name;
        this.health = health;
        this.level = level;
    }
    
    // 추상 메서드: 각 캐릭터가 자신만의 방식으로 구현
    public abstract void attack();
    public abstract void levelUp();
    
    // 공통 행동
    public void takeDamage(int damage) {
        this.health -= damage;
        System.out.println(name + "이(가) " + damage + "의 피해를 입었습니다!");
    }
    
    public void displayInfo() {
        System.out.println("이름: " + name + ", 체력: " + health + ", 레벨: " + level);
    }
}

// ✅ 전사 (방어도 추가)
public class Warrior extends Character {
    private int defense;
    
    public Warrior(String name, int health, int level, int defense) {
        super(name, health, level);
        this.defense = defense;
    }
    
    @Override
    public void attack() {
        System.out.println(name + "이(가) 검으로 강하게 베었다! (피해: " + (10 + defense) + ")");
    }
    
    @Override
    public void levelUp() {
        this.level++;
        this.defense += 5;
        System.out.println(name + "의 방어도가 증가했습니다!");
    }
}

// ✅ 마법사 (마나 추가)
public class Mage extends Character {
    private int mana;
    
    public Mage(String name, int health, int level, int mana) {
        super(name, health, level);
        this.mana = mana;
    }
    
    @Override
    public void attack() {
        if (mana >= 20) {
            System.out.println(name + "이(가) 파이어볼을 시전했다! (피해: " + 25 + ")");
            mana -= 20;
        } else {
            System.out.println("마나가 부족합니다!");
        }
    }
    
    @Override
    public void levelUp() {
        this.level++;
        this.mana += 50;
        System.out.println(name + "의 마나가 증가했습니다!");
    }
    
    public int getMana() {
        return mana;
    }
}

// ✅ 궁수 (명중률 추가)
public class Archer extends Character {
    private double accuracy;
    
    public Archer(String name, int health, int level, double accuracy) {
        super(name, health, level);
        this.accuracy = accuracy;
    }
    
    @Override
    public void attack() {
        double hit = Math.random();
        if (hit < accuracy) {
            System.out.println(name + "이(가) 화살을 명중시켰다! (명중률: " + (accuracy * 100) + "%)");
        } else {
            System.out.println(name + "의 화살이 빗나갔다...");
        }
    }
    
    @Override
    public void levelUp() {
        this.level++;
        this.accuracy += 0.05;
        System.out.println(name + "의 명중률이 증가했습니다!");
    }
}

// ✅ 성기사 (새로운 캐릭터 추가 - 기존 코드 수정 없음!)
public class Paladin extends Character {
    private int mana;
    private int defense;
    
    public Paladin(String name, int health, int level, int mana, int defense) {
        super(name, health, level);
        this.mana = mana;
        this.defense = defense;
    }
    
    @Override
    public void attack() {
        System.out.println(name + "이(가) 신성한 빛으로 공격했다! (피해: 20, 치유: 5)");
        this.health += 5; // 공격하면서 자가 치유
    }
    
    @Override
    public void levelUp() {
        this.level++;
        this.mana += 30;
        this.defense += 3;
        System.out.println(name + "이(가) 성장했습니다!");
    }
}
```

### 3. 다형성을 활용한 통합 관리

```java
public class GameManager {
    private List<Character> characters = new ArrayList<>();
    
    // ✅ 다형성: Character 타입으로 모든 캐릭터 관리
    public void registerCharacter(Character character) {
        characters.add(character);
    }
    
    // ✅ 실제 구현 객체의 메서드가 호출됨 (Runtime Polymorphism)
    public void allCharactersAttack() {
        for (Character character : characters) {
            character.attack(); // 각 캐릭터의 고유한 attack() 실행
        }
    }
    
    public void levelUpAll() {
        for (Character character : characters) {
            character.levelUp(); // 각 캐릭터의 고유한 levelUp() 실행
        }
    }
    
    public void displayAllCharacters() {
        for (Character character : characters) {
            character.displayInfo();
        }
    }
}

// 사용 예시
public class Main {
    public static void main(String[] args) {
        GameManager manager = new GameManager();
        
        // 캐릭터 생성 및 등록
        Character warrior = new Warrior("아르투르", 100, 1, 10);
        Character mage = new Mage("머린", 60, 1, 100);
        Character archer = new Archer("로빈", 80, 1, 0.8);
        Character paladin = new Paladin("우서", 90, 1, 80, 8); // 새로운 타입!
        
        manager.registerCharacter(warrior);
        manager.registerCharacter(mage);
        manager.registerCharacter(archer);
        manager.registerCharacter(paladin);
        
        // 모든 캐릭터가 공격
        manager.allCharactersAttack();
        // 출력:
        // 아르투르이(가) 검으로 강하게 베었다! (피해: 20)
        // 머린이(가) 파이어볼을 시전했다! (피해: 25)
        // 로빈이(가) 화살을 명중시켰다! (명중률: 80.0%)
        // 우서이(가) 신성한 빛으로 공격했다! (피해: 20, 치유: 5)
        
        // 모든 캐릭터 레벨업
        manager.levelUpAll();
    }
}
```

## 핵심 개념 정리

### 📌 상속 (Inheritance)

| 개념 | 설명 |
|------|------|
| **부모 클래스 (Parent Class)** | 공통 속성/메서드 정의 (`Character`) |
| **자식 클래스 (Child Class)** | 부모를 확장하여 고유 속성/메서드 추가 (`Warrior`, `Mage`) |
| **super 키워드** | 부모 클래스의 생성자/메서드 호출 |
| **추상 클래스 (Abstract Class)** | 직접 인스턴스 생성 불가, 서브클래스가 구현할 메서드 강제 |
| **추상 메서드** | 본
