## 모범 답안

이 문제는 **상속(Inheritance)**과 **다형성(Polymorphism)**으로 해결합니다.

### 1️⃣ 공통 기반 클래스 설계
```python
from abc import ABC, abstractmethod
from typing import List

# 기본이 되는 추상 클래스
class Order(ABC):
    def __init__(self, order_id: str, items: List[str], base_price: int):
        self.order_id = order_id
        self.items = items
        self.base_price = base_price
    
    # 공통 기능 (모든 주문이 공유)
    def calculate_total_price(self) -> int:
        """기본 가격 계산"""
        return self.base_price
    
    def get_order_info(self) -> str:
        """공통 주문 정보 출력"""
        return f"주문번호: {self.order_id}, 상품: {self.items}"
    
    # 각 가게마다 다른 처리 방식 (반드시 구현해야 함)
    @abstractmethod
    def calculate_delivery_time(self) -> int:
        """배달 예상 시간 (분)"""
        pass
    
    @abstractmethod
    def get_preparation_details(self) -> str:
        """준비 과정 상세 정보"""
        pass
```

### 2️⃣ 각 가게 타입별 구체적 구현
```python
# 음식점: 조리 시간이 있음
class RestaurantOrder(Order):
    def __init__(self, order_id: str, items: List[str], base_price: int, 
                 cooking_time: int):
        super().__init__(order_id, items, base_price)
        self.cooking_time = cooking_time  # 조리 시간 (분)
    
    def calculate_delivery_time(self) -> int:
        """조리 시간 + 배달 시간"""
        return self.cooking_time + 30  # 기본 배달 30분
    
    def get_preparation_details(self) -> str:
        return f"조리 중... (예상 {self.cooking_time}분)"


# 편의점: 조리 시간 없음
class ConvenienceOrder(Order):
    def calculate_delivery_time(self) -> int:
        """조리 시간 없이 바로 픽업 후 배달"""
        return 15  # 편의점은 빠름
    
    def get_preparation_details(self) -> str:
        return "재고 확인 후 즉시 배송 준비"


# 카페: 사이즈에 따른 준비 시간
class CafeOrder(Order):
    def __init__(self, order_id: str, items: List[str], base_price: int, 
                 drink_size: str):
        super().__init__(order_id, items, base_price)
        self.drink_size = drink_size
    
    def calculate_delivery_time(self) -> int:
        size_time = {"small": 5, "medium": 8, "large": 10}
        return size_time.get(self.drink_size, 8) + 20
    
    def get_preparation_details(self) -> str:
        return f"{self.drink_size.upper()} 사이즈 음료 준비 중..."
```

### 3️⃣ 다형성을 활용한 통일된 처리
```python
class OrderService:
    """모든 주문 타입을 동일하게 처리"""
    
    def process_order(self, order: Order) -> dict:
        """주문 처리 - 어떤 타입의 주문이든 같은 방식으로 처리"""
        return {
            "info": order.get_order_info(),
            "total_price": order.calculate_total_price(),
            "delivery_time": order.calculate_delivery_time(),
            "status": order.get_preparation_details(),
            "estimated_arrival": f"{order.calculate_delivery_time()}분 후"
        }
    
    def batch_process_orders(self, orders: List[Order]):
        """여러 주문을 한 번에 처리 - 타입 상관없음"""
        for order in orders:
            result = self.process_order(order)
            print(result)

# 실제 사용
service = OrderService()

orders = [
    RestaurantOrder("1001", ["버거", "감자튀김"], 12000, cooking_time=15),
    ConvenienceOrder("1002", ["라면", "김밥"], 6000),
    CafeOrder("1003", ["아메리카노"], 4000, drink_size="large")
]

service.batch_process_orders(orders)
```

### 4️⃣ 새로운 기능 추가가 얼마나 쉬운가?
```python

    def calculate_delivery_time(self) -> int:

    def get_preparation_details(self) -> str:
        return "처방전 확인 후 준비 중..."

# 기존 코드 전혀 건드릴 필요 없음!
pharmacy_order = PharmacyOrder("2001", ["감기약"], 5000)
service.process_order(pharmacy_order)  # 바로 적용됨
```

## 핵심 개념 정리

### 🏗️ **상속 (Inheritance)**
- **의미**: 부모 클래스의 특성을 자식 클래스가 물려받음
- **목적**: 코드 중복 제거, 공통 기능 일관성
- **이 사례**: `RestaurantOrder`, `ConvenienceOrder`, `CafeOrder`가 모두 `Order`의 공통 속성 상속
- **이점**:
  - `order_id`, `items`, `base_price` 같은 공통 필드를 한 번만 정의
  - 모든 주문이 `get_order_info()` 기능을 자동으로 가짐

### 🎭 **다형성 (Polymorphism)**
- **의미**: 같은 메서드 이름이지만 각 타입별로 다르게 동작
- **핵심**: `calculate_delivery_time()`이 음식점/편의점/카페마다 다르게 계산
- **추상 메서드 (Abstract Method)**:
  - `@abstractmethod`로 선언된 메서드는 반드시 구현해야 함
  - 자식 클래스에 구현을 강제하는 계약(contract) 역할
- **구현 메서드 vs 추상 메서드**:
  - 구현: 공통 로직 (모든 자식이 같은 방식) → `get_order_info()`
  - 추상: 가변 로직 (자식마다 다른 방식) → `calculate_delivery_time()`

### 🔑 **Open/Closed 원칙 (SOLID 원칙)**
- **열려있음**: 새로운 주문 타입 추가에 열려있음 (약국, 꽃집 등)
- **닫혀있음**: 기존 코드 수정에 닫혀있음 (OrderService 건드릴 필요 없음)
