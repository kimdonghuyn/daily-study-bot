# 상속과 다형성: 동물 관리 시스템

## 모범 답안

**상속과 다형성을 사용하면 다음 3가지 문제를 근본적으로 해결할 수 있습니다:**

### 1️⃣ **코드 중복 제거 (DRY 원칙)**
```java
// ❌ Before: 동물마다 모든 코드를 반복 작성
public class LionManager {
    public void sound() { System.out.println("포효!"); }
    public void eat(String food) { System.out.println("고기 먹음"); }
    public void move() { System.out.println("네발로 걷기"); }
}

public class ParrotManager {
    public void sound() { System.out.println("악!악!"); }
    public void eat(String food) { System.out.println("곡물 먹음"); }
    public void move() { System.out.println("날기"); }
}
// ... 동물마다 계속 반복

// ✅ After: 상속으로 공통 로직 통합
abstract class Animal {
    abstract void sound();  // 각 동물이 자신의 울음소리 구현
    abstract void move();   // 각 동물이 자신의 이동방식 구현
    
    // 공통 로직은 한 번만 정의
    public void feed(String food) {
        System.out.println(food + "를 먹습니다");
    }
}

class Lion extends Animal {
    @Override
    void sound() { System.out.println("포효!"); }
    
    @Override
    void move() { System.out.println("네발로 걷기"); }
}

class Parrot extends Animal {
    @Override
    void sound() { System.out.println("악!악!"); }
    
    @Override
    void move() { System.out.println("날기"); }
}
```

### 2️⃣ **유연한 확장성 (Open-Closed Principle)**
```java
// 새로운 동물 추가가 간단함
class Goldfish extends Animal {
    @Override
    void sound() { System.out.println("...(소리없음)"); }
    
    @Override
    void move() { System.out.println("헤엄치기"); }
}

// 기존 코드 수정 없음! ✨
```

### 3️⃣ **다형성으로 통일된 인터페이스 제공**
```java
// 동물의 종류와 상관없이 동일하게 처리 가능
List<Animal> animals = new ArrayList<>();
animals.add(new Lion());
animals.add(new Parrot());
animals.add(new Goldfish());

// 반복문 하나로 모든 동물 관리
for (Animal animal : animals) {
    animal.sound();    // 각 동물의 울음소리가 자동으로 호출됨
    animal.move();     // 각 동물의 이동방식이 자동으로 호출됨
    animal.feed("먹이");
}

// 출력:
// 포효!
// 네발로 걷기
// 먹이를 먹습니다
// 악!악!
// 날기
// 먹이를 먹습니다
// ...
```

## 핵심 개념 정리

### 📌 **상속 (Inheritance)**
- **목적**: 공통된 속성과 기능을 부모 클래스에서 정의하고 재사용
- **효과**: 코드 중복 제거, 유지보수성 향상
- **구조**: `class 자식클래스 extends 부모클래스`

### 📌 **다형성 (Polymorphism)**
- **목적**: 같은 메서드명으로 다양한 동작을 구현 (오버라이딩)
- **효과**: 객체의 실제 타입에 따라 자동으로 올바른 메서드 호출
- **원리**: 런타임에 실제 객체의 메서드가 실행됨 (동적 바인딩)

### 📌 **추상 클래스 (Abstract Class)**
```java
abstract class Animal {
    // 반드시 자식이 구현해야 하는 메서드
    abstract void sound();
    
    // 모든 동물이 공통으로 사용하는 기능
    public void sleep() {
        System.out.println("자고 있습니다");
    }
}
```

### 📌 **메서드 오버라이딩 (Method Overriding)**
```java
class Tiger extends Animal {
    @Override  // 부모 메서드를 자식에서 다시 구현
    void sound() {
        System.out.println("어흥!");  // 부모와 다른 구현
    }
}
```

## 실무 포인트

### 🎯 **SOLID 원칙 적용**

**1. Single Responsibility (단일 책임)**
```java
// 각 동물은 자신의 행동만 책임짐
class Lion extends Animal {
    @Override
    void sound() { /* 사자의 울음만 담당 */ }
}
```

**2. Open/Closed (확장에 열려있고 수정에 닫혀있음)**
```java
// 새 동물 추가 시 기존 코드 수정 불필요
class Elephant extends Animal { /* ... */ }

// ZooManager는 여전히 동일하게 동작
```

**3. Liskov Substitution (리스코프 치환)**
```java
Animal animal = new Lion();   // OK
animal = new Parrot();         // OK
animal = new Goldfish();       // OK
// 어느 것이든 Animal로 취급 가능 (치환 가능)
```

### 🏢 **실제 프로젝트 예시**

```java
// 동물원 관리 시스템
public class Zoo {
    private List<Animal> animals = new ArrayList<>();
    
    public void addAnimal(Animal animal) {
        animals.add(animal);  // 모든 동물 타입 수용 가능
    }
    
    public void dailySchedule() {
        for (Animal animal : animals) {
            animal.sound();
            animal.feed("일일 식사");
            animal.move();
            System.out.println("---");
        }
    }
    
    public void performShow() {
        // 새 동물이 추가되면 자동으로 show에 포함됨
        for (Animal animal : animals) {
            animal.sound();  // 다형성 덕분에 자동 처리
        }
    }
}
```

### ⚠️ **주의사항**

```java
// ❌ 잘못된 사용: 타입 체크를 반복하는 것
for (Animal animal : animals) {
    if (animal instanceof Lion) {
        ((Lion) animal).roar();
    } else if (animal instanceof Parrot) {
        ((Parrot) animal).squawk();
    }
    // 이렇게 쓰면 다형성의 이점을 포기하는 것!
}

// ✅ 올바른 사용: 다형성 활용
for (Animal animal : animals) {
    animal.sound();  // 각 동물이 자신의 방식대로 호출됨
}
```

### 💡 **언제 상속을 사용할까?**
- ✅ **"~은 ~이다"** 관계일 때 (Lion **is-a** Animal)
- ✅ 공통 기능이 20% 이상일 때
- ✅ 향후 확장 가능성이 있을 때

- ❌ **"~은 ~을 가진다"** 관계는 조합(Composition) 사용
```java
// ❌ 잘못된 설계
class Wing extends Animal { }  // 날개가 동물이 아님!

// ✅ 올바른 설계
class Bird extends Animal {
    private Wing wing;  // 날개를 속성으로 가짐
}
```

---

**핵심 요약**: 상속과 다형성은 **"변하는 부분과 변하지 않는 부분을 분리"**하여, 새로운 기능 추가 시 기존 코드를 건드리지 않고도 확장 가능한 구조를 만드는 것입니다. 이것이 바로 **유지보수하기 좋은 코드**입니다! 🚀
