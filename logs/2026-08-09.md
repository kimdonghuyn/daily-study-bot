## 📚 모범 답안 & 개념 정리

### 1. 🔧 문제 상황

# 상속과 다형성을 통한 무기 시스템 설계

## 모범 답안

### 문제의 근본 원인
현재 코드는 **`if-else` 또는 `switch` 문으로 무기 타입을 매번 확인**하고 있습니다. 이를 **Open-Closed Principle 위반**이라고 합니다.
- 확장에는 열려있지 않음 (새 무기 추가 시마다 조건문 수정)
- 수정에는 닫혀있지 않음 (기존 코드를 건드려야 함)

### 상속과 다형성으로 해결하기

```python
# ❌ 문제 있는 코드 (Before)
class Player:
    def attack(self, weapon_type):
        if weapon_type == "sword":
            print("3칸 베기")
        elif weapon_type == "bow":
            print("원거리 사격")
        elif weapon_type == "staff":
            print("마법 발동")
        elif weapon_type == "hammer":  # 새 무기 추가할 때마다 수정
            print("강력한 내려찍기")
        # 계속 추가되는 조건문...

# ✅ 개선된 코드 (After)
from abc import ABC, abstractmethod

# 1단계: 추상 클래스로 계약(Interface) 정의
class Weapon(ABC):
    """모든 무기가 구현해야 할 계약"""
    @abstractmethod
    def attack(self):
        pass
    
    @abstractmethod
    def get_damage(self):
        pass

# 2단계: 각 무기별로 구체적 구현
class Sword(Weapon):
    def attack(self):
        return "3칸 베기"
    
    def get_damage(self):
        return 20

class Bow(Weapon):
    def attack(self):
        return "원거리 사격 (거리: 10칸)"
    
    def get_damage(self):
        return 15

class Staff(Weapon):
    def attack(self):
        return "마법 발동 - 불의 구슬"
    
    def get_damage(self):
        return 25

class Hammer(Weapon):
    def attack(self):
        return "강력한 내려찍기 (범위 피해)"
    
    def get_damage(self):
        return 30

# 3단계: 플레이어는 무기 타입을 신경 쓰지 않음
class Player:
    def __init__(self, name: str, weapon: Weapon):
        self.name = name
        self.weapon = weapon
    
    def attack(self):
        """다형성: 실제 무기 객체에 위임"""
        action = self.weapon.attack()
        damage = self.weapon.get_damage()
        print(f"{self.name}이(가) {action} [데미지: {damage}]")
    
    def change_weapon(self, new_weapon: Weapon):
        """새 무기로 변경"""
        self.weapon = new_weapon

# 4단계: 사용 (새 무기 추가 시 기존 코드는 수정 불필요!)
player = Player("영웅", Sword())
player.attack()  # 영웅이(가) 3칸 베기 [데미지: 20]

player.change_weapon(Bow())
player.attack()  # 영웅이(가) 원거리 사격 (거리: 10칸) [데미지: 15]

# 새 무기 추가: Player 클래스 수정 없음!
class Spear(Weapon):
    def attack(self):
        return "창 찌르기 (빠른 연격)"
    
    def get_damage(self):
        return 18

player.change_weapon(Spear())
player.attack()  # 영웅이(가) 창 찌르기 (빠른 연격) [데미지: 18]
```

## 핵심 개념 정리

### 1️⃣ **상속 (Inheritance)**
- **정의**: 자식 클래스가 부모 클래스의 속성과 메서드를 물려받음
- **여기서의 역할**: 모든 무기가 `Weapon` 추상 클래스를 상속
- **효과**: 코드 재사용, 공통 인터페이스 정의

```python
class Sword(Weapon):  # Weapon을 상속
    pass
```

### 2️⃣ **다형성 (Polymorphism)**
- **정의**: 같은 메서드명으로 다른 동작을 수행
- **종류**:
  - **메서드 오버라이딩**: 자식 클래스가 부모 메서드 구현
  - **동적 바인딩**: 런타임에 실제 객체 타입에 따라 메서드 실행

```python
# 같은 attack() 메서드, 다른 동작
weapon = Sword()
weapon.attack()  # "3칸 베기"

weapon = Bow()
weapon.attack()  # "원거리 사격"
```

### 3️⃣ **추상 클래스 / 인터페이스**
- **목적**: 자식 클래스가 반드시 구현해야 할 메서드 명시
- **장점**: 계약(Contract) 역할 → 예측 가능한 설계

```python
@abstractmethod
def attack(self):
    pass  # 자식은 반드시 구현해야 함
```

### 4️⃣ **Open-Closed Principle (확장-수정 원칙)**
| 원칙 | Before | After |
|------|--------|-------|
| **확장에 열려있음** | ❌ 새 무기 추가 시 if-else 수정 | ✅ 새 클래스 추가만으로 확장 |
| **수정에 닫혀있음** | ❌ Player 클래스 계속 수정 | ✅ Player 클래스 수정 불필요 |

### 🎯 **2. 무기 조합 시스템 확장 (보너스)**

```python
# 데코레이터 패턴으로 무기 강화
class EnhancedWeapon(Weapon):
    def __init__(self, weapon: Weapon, enhancement: str):
        self.weapon = weapon
        self.enhancement = enhancement
    
    def attack(self):
        return f"{self.weapon.attack()} + {self.enhancement}"
    
    def get_damage(self):
        return self.weapon.get_damage() + 10

# 사용
sword = Sword()
enhanced_sword = EnhancedWeapon(sword, "불 속성")
player.change_weapon(enhanced_sword)
player.attack()  # 3칸 베기 + 불 속성 [데미지: 30]
```

### 🎯 **3. 실제 게임 엔진에서의 패턴**

```python
# Unity/Unreal처럼 플러그인 방식
class WeaponFactory:
    """무기 생성 팩토리"""
    weapons = {}
    
    @classmethod
    def register_weapon(cls, name: str, weapon_class):
        cls.weapons[name] = weapon_class
    
    @classmethod
    def create(cls, name: str) -> Weapon:
        return cls.weapons[name]()

# 게임 시작 시 무기 등록
WeaponFactory.register_weapon("sword", Sword)
WeaponFactory.register_weapon("bow", Bow)

# 새 무기 DLC? 간단히 추가
WeaponFactory.register_weapon("spear", Spear)

# 플레이어 생성
weapon = WeaponFactory.create("sword")
player = Player("영웅", weapon)
```
