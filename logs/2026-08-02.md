## 모범 답안

이 상황은 **상속과 다형성**의 전형적인 사용 사례입니다.

### 핵심 해결 방안

```python
# 1. 공통 기능을 담는 부모 클래스 (상속의 기초)
class Character:
    def __init__(self, name, hp, attack_power):
        self.name = name
        self.hp = hp
        self.attack_power = attack_power
    
    # 공통 메서드
    def take_damage(self, damage):
        self.hp -= damage
        print(f"{self.name}이(가) {damage}의 피해를 입었습니다. 남은 HP: {self.hp}")
    
    # 각 캐릭터가 구현해야 할 메서드 (다형성)
    def attack(self):
        raise NotImplementedError("attack() 메서드를 구현하세요")
    
    def defend(self):
        raise NotImplementedError("defend() 메서드를 구현하세요")
    
    def special_ability(self):
        raise NotImplementedError("special_ability() 메서드를 구현하세요")


# 2. 캐릭터별 구현 (다형성 실현)
class Warrior(Character):
    def attack(self):
        damage = self.attack_power * 1.5
        print(f"{self.name}이(가) 강력한 검 공격을 날렸습니다! 데미지: {damage}")
        return damage
    
    def defend(self):
        print(f"{self.name}이(가) 방패로 방어했습니다. 방어력 UP!")
    
    def special_ability(self):
        print(f"{self.name}이(가) 분노 상태로 돌입했습니다! 공격력 2배!")
        self.attack_power *= 2


class Mage(Character):
    def __init__(self, name, hp, attack_power, mana=100):
        super().__init__(name, hp, attack_power)
        self.mana = mana
    
    def attack(self):
        if self.mana >= 20:
            damage = self.attack_power * 2.5  # 마법사는 높은 공격력
            self.mana -= 20
            print(f"{self.name}이(가) 마법 미사일을 발동했습니다! 데미지: {damage}")
            return damage
        else:
            print("마나가 부족합니다!")
            return 0
    
    def defend(self):
        print(f"{self.name}이(가) 마법 방패를 생성했습니다.")
    
    def special_ability(self):
        print(f"{self.name}이(가) 모든 적에게 광역 마법을 시전했습니다!")
        self.mana -= 50


class Archer(Character):
    def attack(self):
        damage = self.attack_power * 1.2
        print(f"{self.name}이(가) 화살을 정확하게 쏘았습니다! 데미지: {damage}")
        return damage
    
    def defend(self):
        print(f"{self.name}이(가) 재빠르게 몸을 날렸습니다.")
    
    def special_ability(self):
        print(f"{self.name}이(가) 연속 사격 스킬을 사용했습니다!")


# 3. 다형성의 강력함 - 같은 방식으로 다르게 동작
def battle_system(characters):
    """모든 캐릭터를 동일한 인터페이스로 처리"""
    for character in characters:
        character.attack()  # 각 캐릭터의 attack()이 다르게 동작
        character.special_ability()
        print()


# 사용 예
if __name__ == "__main__":
    warrior = Warrior("아서스", hp=200, attack_power=50)
    mage = Mage("메디브", hp=100, attack_power=80)
    archer = Archer("레가스", hp=150, attack_power=60)
    
    characters = [warrior, mage, archer]
    
    battle_system(characters)  # 하나의 함수로 모든 캐릭터 처리!
```

## 핵심 개념 정리

### 🏛️ **상속 (Inheritance)**
- **정의**: 부모 클래스의 속성과 메서드를 자식 클래스가 물려받는 것
- **목적**: 중복 코드 제거, 코드 재사용성 증대
- **이 예제에서**:
  - `Character`가 부모 클래스
  - `Warrior`, `Mage`, `Archer`가 자식 클래스
  - 공통 속성(`hp`, `attack_power`) 한 번만 정의

### 🎭 **다형성 (Polymorphism)**
- **정의**: 같은 이름의 메서드가 객체에 따라 다르게 동작하는 것
- **종류**:
  - **메서드 오버라이딩**: 부모의 메서드를 자식이 재정의 (`attack()`)
  - **메서드 오버로딩**: 같은 이름, 다른 파라미터 (Python에선 제한적)
  
- **이 예제에서**:
  - 모든 캐릭터가 `attack()`을 가지지만 다르게 동작
  - `battle_system()`은 캐릭터 종류를 몰라도 동작

### 📦 **인터페이스 계약**
```python
# 부모 클래스에서 정의한 "계약"
def attack(self):
    raise NotImplementedError()  # 반드시 구현하도록 강제
```
- 모든 자식은 `attack()` 구현을 의무화
- 일관된 인터페이스 보장

### ✅ **이 설계의 장점**

| 항목 | 효과 |
|------|------|
| **코드 중복 제거** | `take_damage()` 한 번만 작성 |
| **새 캐릭터 추가 용이** | `Character` 상속 → 3개 메서드 구현 → 완성 |
| **변경에 강함** | 기본 로직 변경 시 `Character`만 수정 |
| **테스트 용이** | 각 캐릭터를 동일한 방식으로 테스트 |
