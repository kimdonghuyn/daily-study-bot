### 1단계: 상속으로 중복 코드 제거

```java
// ✅ 부모 클래스: 공통 속성과 기본 동작 정의
public abstract class Character {
    protected String name;
    protected int hp;
    protected int attackPower;
    
    public Character(String name, int hp, int attackPower) {
        this.name = name;
        this.hp = hp;
        this.attackPower = attackPower;
    }
    
    // 각 캐릭터마다 다르게 구현되어야 하는 메서드
    abstract void attack();
    
    // 공통 메서드
    public void takeDamage(int damage) {
        this.hp -= damage;
        System.out.println(name + "이(가) " + damage + "의 피해를 입었습니다.");
    }
    
    public int getHp() {
        return hp;
    }
}

// ✅ 자식 클래스들: 각각의 고유한 공격 방식만 구현
public class Warrior extends Character {
    public Warrior(String name) {
        super(name, 150, 20);
    }
    
    @Override
    void attack() {
        System.out.println(name + "의 검 공격! 데미지: " + attackPower);
    }
}

public class Mage extends Character {
    public Mage(String name) {
        super(name, 80, 35);
    }
    
    @Override
    void attack() {
        System.out.println(name + "의 파이어볼! 데미지: " + attackPower * 2);
    }
}

public class Archer extends Character {
    public Archer(String name) {
        super(name, 100, 25);
    }
    
    @Override
    void attack() {
        System.out.println(name + "의 화살 공격! 데미지: " + attackPower);
    }
}
```

### 2단계: 다형성으로 통일된 인터페이스 제공

```java
// ✅ 다형성의 핵심: 부모 타입으로 자식 객체들을 관리
public class GameBattle {
    private List<Character> characters = new ArrayList<>();
    
    // 어떤 캐릭터든 추가 가능
    public void addCharacter(Character character) {
        characters.add(character);
    }
    
    // 모든 캐릭터에게 한 번에 공격 명령
    public void allAttack() {
        for (Character character : characters) {
            character.attack(); // 각자의 방식으로 공격!
        }
    }
    
    // 모든 캐릭터의 상태 확인
    public void printStatus() {
        for (Character character : characters) {
            System.out.println("체력: " + character.getHp());
        }
    }
}

// ✅ 사용 예
public static void main(String[] args) {
    GameBattle battle = new GameBattle();
    
    // 다양한 캐릭터 추가 (부모 타입으로 관리)
    battle.addCharacter(new Warrior("아서"));
    battle.addCharacter(new Mage("메를린"));
    battle.addCharacter(new Archer("로빈"));
    
    // 실제 자신의 클래스가 무엇인지 알 필요 없음!
    battle.allAttack();
    
    /* 출력:
    아서의 검 공격! 데미지: 20
    메를린의 파이어볼! 데미지: 70
    로빈의 화살 공격! 데미지: 25
    */
}
```

## 핵심 개념 정리

### **상속 (Inheritance)**
- **목적**: 공통된 속성과 메서드를 부모 클래스에 정의하여 **코드 중복 제거**
- **장점**:
  - 이름, 체력, 기본 공격력 등 **공통 코드를 한 곳에서 관리**
  - 새로운 캐릭터 추가 시 **부모 클래스의 코드 재사용**
  - 공통 메서드(takeDamage) 수정 시 **모든 자식 클래스에 즉시 반영**

### **다형성 (Polymorphism)**
- **목적**: 같은 인터페이스로 **다른 동작을 수행**
  - 메서드 오버라이딩(Method Overriding): `attack()`을 각 클래스가 다르게 구현
  - 런타임 다형성: 실제 객체의 타입에 따라 **올바른 메서드가 자동 호출**

- **핵심 원리**:
```java
Character warrior = new Warrior("아서");
Character mage = new Mage("메를린");

warrior.attack(); // ✅ Warrior의 attack() 실행
mage.attack();    // ✅ Mage의 attack() 실행
```

### **상속 + 다형성의 시너지**
| 문제 | 상속만 | 다형성만 | 상속+다형성 |
|------|-------|---------|----------|
| 코드 중복 | ✅ 해결 | ❌ | ✅ 해결 |
| 확장성 | ⚠️ 부분적 | ❌ | ✅ 우수 |
| 통일된 관리 | ❌ | ✅ 해결 | ✅ 해결 |
