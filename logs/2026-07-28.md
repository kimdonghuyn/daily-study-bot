### 1단계: 상속으로 공통 기능 통합

```python
# 기본 캐릭터 클래스 (부모 클래스)
class Character:
    def __init__(self, name: str, hp: int, level: int = 1):
        self.name = name
        self.hp = hp
        self.max_hp = hp
        self.level = level
        self.exp = 0
    
    # 모든 캐릭터가 공유하는 기능
    def take_damage(self, damage: int):
        self.hp = max(0, self.hp - damage)
        print(f"{self.name}이(가) {damage}의 피해를 입었습니다. (남은 HP: {self.hp})")
    
    def gain_exp(self, amount: int):
        self.exp += amount
        if self.exp >= 100:
            self.level_up()
    
    def level_up(self):
        self.level += 1
        self.exp = 0
        self.max_hp += 10
        self.hp = self.max_hp
        print(f"{self.name}이(가) {self.level}레벨로 상승했습니다!")
    
    # 추상 메서드: 자식 클래스에서 반드시 구현
    def attack(self, target: 'Character'):
        raise NotImplementedError("attack 메서드를 구현해야 합니다")
```

### 2단계: 다형성으로 각 캐릭터 타입 구현

```python
# 전사 클래스
class Warrior(Character):
    def __init__(self, name: str, hp: int = 150):
        super().__init__(name, hp)
        self.weapon = "검"
    
    def attack(self, target: Character):
        damage = 25
        print(f"\n[전사 {self.name}] {self.weapon}로 베기! 데미지: {damage}")
        target.take_damage(damage)


# 마법사 클래스
class Mage(Character):
    def __init__(self, name: str, hp: int = 80):
        super().__init__(name, hp)
        self.mana = 100
    
    def attack(self, target: Character):
        if self.mana < 30:
            print(f"\n[마법사 {self.name}] 마나가 부족합니다!")
            return
        
        damage = 40
        self.mana -= 30
        print(f"\n[마법사 {self.name}] 파이어볼 발동! 데미지: {damage}, (남은 마나: {self.mana})")
        target.take_damage(damage)


# 궁수 클래스
class Archer(Character):
    def __init__(self, name: str, hp: int = 100):
        super().__init__(name, hp)
        self.arrows = 30
    
    def attack(self, target: Character):
        if self.arrows <= 0:
            print(f"\n[궁수 {self.name}] 화살이 없습니다!")
            return
        
        damage = 20
        self.arrows -= 1
        print(f"\n[궁수 {self.name}] 화살 발사! 데미제: {damage}, (남은 화살: {self.arrows})")
        target.take_damage(damage)
```

### 3단계: 다형성의 강력함 - 동일한 인터페이스로 모든 타입 처리

```python
# 게임 관리 시스템
class Game:
    def __init__(self):
        self.characters: list[Character] = []
    
    def add_character(self, character: Character):
        self.characters.append(character)
    
    # 핵심: 캐릭터의 실제 타입을 신경 쓰지 않음
    def simulate_battle(self, attacker: Character, defender: Character):
        """
        다형성 덕분에 공격자의 타입이 뭐든 
        같은 메서드로 처리 가능
        """
        attacker.attack(defender)
        attacker.gain_exp(10)
    
    def display_status(self):
        for char in self.characters:
            print(f"[{char.__class__.__name__}] {char.name} - "
                  f"HP: {char.hp}/{char.max_hp}, Lv: {char.level}")


# 실제 사용
game = Game()
warrior = Warrior("아르토리우스")
mage = Mage("간달프")
archer = Archer("레고라스")

game.add_character(warrior)
game.add_character(mage)
game.add_character(archer)

# 동일한 메서드로 모든 캐릭터 처리
game.simulate_battle(warrior, mage)
game.simulate_battle(mage, archer)
game.simulate_battle(archer, warrior)

game.display_status()
```

## 핵심 개념 정리

### 📌 **상속 (Inheritance)**
- **목적**: 공통 기능을 부모 클래스에 집중화
- **이점**:
  - 코드 중복 제거 (DRY 원칙)
  - 공통 기능 한 곳에서 관리
  - 자동으로 모든 자식 클래스에 적용
- **구조**: `Character` (부모) ← `Warrior`, `Mage`, `Archer` (자식)

### 📌 **다형성 (Polymorphism)**
- **목적**: 같은 이름의 메서드가 다르게 동작
- **종류**:
  - **메서드 오버라이딩**: 자식이 부모의 메서드를 다시 구현
    ```python
    # 부모: attack() 선언만
    # 자식들: attack() 각각 다르게 구현
    ```
  - **메서드 오버로딩**: 같은 이름, 다른 매개변수 (Python은 제한적)
  
- **핵심 패턴**:
  ```python
  # 타입을 구분하지 않고 처리
  for character in characters:
      character.attack(enemy)  # 각자의 attack() 실행됨
  ```

### 📌 **Liskov Substitution Principle (리스코프 치환 원칙)**
- **원칙**: 자식 클래스는 부모 클래스 대신 사용 가능해야 함
- **예시**: `Game.simulate_battle(character)`는 모든 Character 타입을 받을 수 있음

### 📌 **Open/Closed Principle (개방-폐쇄 원칙)**
- **개방**: 새로운 캐릭터 타입 추가에 개방
- **폐쇄**: 기존 코드 수정에 폐쇄
- 새 Paladin 클래스 추가 시 Game, simulate_battle은 수정 불필요
