오늘의 백엔드 학습 세션을 시작해줘.

## 1단계 — 현재 상태 대시보드

Bash로 프로필과 오늘 토픽을 가져온다:

```bash
node --env-file=.env scripts/today-topic.js 2>/dev/null || node scripts/today-topic.js
```

그리고 GitHub에서 profile.json을 읽어 XP/레벨/스트릭 정보를 가져온다:
```bash
node --env-file=.env -e "
const LEVEL_XP = [0, 100, 250, 500, 900, 1400, 2000, 2700, 3500];
const res = await fetch('https://api.github.com/repos/kimdonghuyn/daily-study/contents/profile.json?ref=master', {
  headers: { Authorization: 'Bearer ' + process.env.STUDY_GITHUB_TOKEN, 'User-Agent': 'bot' }
});
if (!res.ok) { console.log('{}'); process.exit(0); }
const data = await res.json();
const p = JSON.parse(Buffer.from(data.content, 'base64').toString('utf-8'));
let lv = 1;
for (let i = 0; i < LEVEL_XP.length; i++) { if (p.totalXP >= LEVEL_XP[i]) lv = i+1; else break; }
const nextXP = LEVEL_XP[lv] ?? null;
console.log(JSON.stringify({ totalXP: p.totalXP, level: lv, nextXP, streak: p.streak||0, questsCompleted: p.questsCompleted||0, badges: p.badges||[], dayNumber: p.dayNumber||0 }));
" 2>/dev/null || echo "{}"
```

두 결과를 합쳐서 아래 형식으로 대시보드를 출력한다.
프로필 조회 실패 시 XP/레벨 부분은 "-"로 표시하되 학습은 정상 진행:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 학습 현황
  레벨      Lv.{level}
  XP        {totalXP} / {nextXP} XP
  스트릭    {streak}일 연속 🔥
  완료      {questsCompleted}개
  뱃지      {badges 나열 or "없음"}

📅 오늘의 학습
  Day {dayNumber+1}  |  토픽 {topicIndex+1} / 20
  🎯 {topic}
  📌 {typeLabel}
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 2단계 — 학습 방식 선택

대시보드 출력 후 사용자에게 묻는다:

```
어떤 방식으로 학습할까요?

1️⃣  설명 → 내가 요약  (파인만 기법)
     개념 설명을 듣고, 핵심을 내 말로 설명해보기

2️⃣  문제 먼저  (능동 회상)
     설명 없이 바로 질문 → 막히면 힌트

3️⃣  대화식  (소크라테스)
     Claude가 질문으로 유도, 내가 스스로 발견

번호를 입력하거나 그냥 "시작"이라고 하면 1번으로 진행합니다.
```

## 3단계 — 유형 × 방식별 학습 진행

### type = `concept` (개념 설명)

**방식 1 — 파인만:**
1. 핵심 개념을 실무 관점으로 깊이 설명 (왜 쓰는지, 트레이드오프, 실제 코드/상황)
2. "이제 이 개념을 면접관에게 설명한다고 생각하고 핵심만 요약해보세요." 대기
3. 사용자 요약에 보완점 피드백

**방식 2 — 능동 회상:**
1. 설명 없이 바로 핵심 질문 ("JVM GC는 어떻게 동작하나요?")
2. 막히면 단계적 힌트 ("힌트: 힙 영역을 생각해보세요")
3. 마지막에 완전한 설명 제공

**방식 3 — 소크라테스:**
1. "Java에서 메모리 누수가 발생하면 어떤 증상이 나타날까요?" 같은 유도 질문
2. 답변 따라 꼬리질문으로 깊이 파고듦
3. 사용자가 스스로 개념에 도달하게 유도

---

### type = `problem` (문제 상황)

오늘의집/무신사/컬리/올리브영/배달의민족 중 토픽에 맞는 회사의 실제 장애 시나리오 제시.
구체적인 증상, 로그, 수치 포함.

**방식 1:** 시나리오 → 접근법 서술 → 피드백
**방식 2:** 시나리오만 주고 바로 질문 → 막히면 단서 추가
**방식 3:** 질문으로 원인 좁혀나가기 ("로그에서 어떤 패턴을 찾겠습니까?")

---

### type = `interview` (면접 질문)

실제 면접처럼 진행.

**방식 1:** 질문 → 답변 → 모범 답안과 비교
**방식 2:** 질문만 던지고 바로 답변 요구, 꼬리질문 3~4개 연속
**방식 3:** 면접관이 질문으로 유도 ("그 개념의 핵심이 뭐라고 생각하세요?")

모든 질문 끝난 후 총평 제공.

## 4단계 — 세션 종료 및 자동 저장

사용자가 "끝", "완료", "저장", "그만" 입력 또는 학습이 자연스럽게 마무리되면:

**1. 요약 생성** (아래 형식 엄수):
```
✅ 핵심 개념 요약 (2~3줄)
🔑 놓치지 말아야 할 포인트
  • [포인트 1]
  • [포인트 2]
  • [포인트 3]
📚 내일 복습 포인트: [핵심 키워드 1~2개]
```

**2. Redis + GitHub 저장:**
```bash
node --env-file=.env scripts/save-study.js "{topic}" "{type}" << 'SUMMARY_EOF'
[위 요약 내용]
SUMMARY_EOF
```
`{type}`은 today-topic.js에서 가져온 `type` 값 (concept / problem / interview)

**3. 완료 메시지:**
```
✅ 학습 저장 완료!
내일 아침 08:00 Slack으로 복습 요약 + 질문이 발송됩니다.
```

## 주의사항
- 설명은 3년차 실무 개발자 수준 (이론 암기보다 "왜 쓰는지" 중심)
- 틀린 답변엔 바로 정답 말하지 말고 힌트로 유도
- `.env`에 `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` 필요
- `STUDY_GITHUB_TOKEN` 없거나 만료 시 프로필은 "-"로 표시하되 학습은 정상 진행
